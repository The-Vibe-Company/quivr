# __PLUGIN_ID__

A Quivr normalizer plugin generated by `quivr plugin init`. It turns
`text/markdown` Blobs into a Manifest with a `title` Part and one `section`
Part per heading.

## Set up

Python 3.12 or later. Install the Quivr Plugin SDK from the Quivr repository:

```bash
python3 -m venv .venv
. .venv/bin/activate
pip install -e <path to a quivr-v2 checkout>/sdks/python
# or: pip install "quivr-plugin-sdk @ git+https://github.com/The-Vibe-Company/quivr-v2#subdirectory=sdks/python"
```

## Develop

```bash
quivr plugin inspect .                              # validate quivr-plugin.yaml
python3 -m unittest discover -s tests               # unit tests
quivr plugin dev --fixture fixtures/sample.json     # run the plugin and replay the fixture once
quivr plugin dev --fixture fixtures/sample.json --watch   # replay after every source change
quivr plugin test --report contract-report.json     # certify the plugin with the Contract Runner
```

`quivr plugin test` runs every fixture in `fixtures/`, replays each
idempotency key, enforces `timeout_ms`, sends invalid requests, and exits
`0` only when the engine can safely invoke the plugin.

`quivr plugin dev` starts `run.command` from `quivr-plugin.yaml` with
`QUIVR_PLUGIN_HOST` and `QUIVR_PLUGIN_PORT` set, waits for `GET /v0/health`,
checks that `GET /v0/discovery` serves the digest of this exact
`quivr-plugin.yaml`, then sends the fixture's input through a `file://`
reference and validates the response with the engine's Manifest rules.

## Layout

| Path | Purpose |
| --- | --- |
| `quivr-plugin.yaml` | Identity, compatibility, media types, configuration schema, run command |
| `__PLUGIN_MODULE__/normalizer.py` | The normalizer |
| `__PLUGIN_MODULE__/__main__.py` | Serves the plugin over HTTP |
| `fixtures/` | Invocation fixtures and their input files |
| `tests/` | Unit tests using `quivr_plugin.testing` |

Raise `quivr_plugin.RetryableError` for transient failures (the engine retries)
and `quivr_plugin.TerminalError` when the input can never be normalized. Every
change to `quivr-plugin.yaml` changes its digest; restart the plugin so
discovery serves the new one.
