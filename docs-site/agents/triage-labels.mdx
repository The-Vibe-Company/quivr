title: "Triage labels"
description: "The five triage labels"
---

The engineering skills use five canonical triage roles. The Linear labels for this repository use the same names.

| Label in Matt Pocock's skills | Label in Linear | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | A maintainer must evaluate the issue |
| `needs-info` | `needs-info` | More information is required from the reporter |
| `ready-for-agent` | `ready-for-agent` | Fully specified and safe for an autonomous agent session |
| `ready-for-human` | `ready-for-human` | Requires human judgment or implementation |
| `wontfix` | `wontfix` | Will not be actioned |

When a skill refers to a canonical role, apply the corresponding Linear label from this table.
