- [alerts](/plugins/alerts): the first-party keyword alert plugin

## Guides {#guides}

- [Run a connector plugin](/plugins/run-a-connector-plugin): pin a connector plugin and read the health it reports
- [Write a normalizer](/plugins/write-a-normalizer): from `quivr plugin init` to a searchable, observable Record
- [Write a retrieval plugin](/plugins/write-a-retrieval-plugin): decide how search results are found and ranked, under named profiles
- [Write an ingestion plugin](/plugins/write-an-ingestion-plugin): decide how articles are cut and embedded, and move a Corpus onto it
- [pdf-text](/plugins/pdf-text): the reference PDF normalizer, one Part per page
- [RSS and Atom connector plugin](/plugins/rss): the first-party RSS and Atom connector plugin
- [Quivr Plugin SDK for Go](/sdks/go): write, test and certify a source collector or an ingestion plugin in Go
- [Quivr Plugin SDK for Python](/sdks/python): write, test and run a Python normalizer
