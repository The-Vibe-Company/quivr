description: Runtime guide for running Armada workers on Conductor Cloud. Use when an Armada coordinator must launch a worker on a ticket, send it a message, check whether a silent worker is still alive, or stop and archive it. This project's Armada instructions come from the Armada CLI the brief installed. Run `armada skill armada-runtime-conductor` and follow its output; for a linked file, `armada skill armada-runtime-conductor <file>`. If the command is missing, install the version your brief names.
