description: Working one ticket as an Armada worker agent. Use when you were launched on a ticket by an Armada coordinator, or asked to claim, plan, implement and ship one ticket of a project that has an armada.toml. Covers the claim, background liveness, progress reports, questions to the coordinator, the green pull request and the hand-back. A worker never merges.

This project's Armada instructions come from the Armada CLI the brief installed. Run `armada skill armada-worker` and follow its output; for a linked file, `armada skill armada-worker <file>`. If the command is missing, install the version your brief names.
